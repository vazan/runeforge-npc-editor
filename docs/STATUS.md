## Point de reprise

La prochaine tranche M7–M9 porte sur le graphe de nœuds : un nœud de choix (`select`/`menu`) à une sortie par option, puis la relecture d'un script existant en graphe modifiable avec annulation, puis l'essai sur un serveur rAthena réellement isolé. Ne pas utiliser le serveur local de développement comme environnement de test tant qu'une copie jetable avec base de données dédiée n'est pas établie.

**Mises à jour (DEC-046)** : les prochaines étapes sont **du propriétaire** — créer la clé de signature (`pnpm release:keygen --out <fichier hors du dépôt>`), reconstruire l'application avec elle, puis publier une première release de test et la vérifier de bout en bout contre le vrai GitHub (`RELEASE.md`, § 4). Tant que cela n'est pas fait, l'application répond « cette version ne peut pas vérifier les mises à jour » (`not_configured`). **Linux (DEC-047)** : l'essai de la fenêtre, et d'une vraie mise à jour dans la fenêtre, reste à faire sur une machine de bureau Linux, ou ici avec WebKit WebDriver, `tauri-driver` et un serveur d'affichage virtuel — **non installés : accord du propriétaire à demander** (téléchargements dans WSL).
